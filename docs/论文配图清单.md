## 使用说明

1. 在 Word 中搜索 **「此处插入图片」**，可快速定位全部 10 处占位；
2. 按下面的编号找到对应说明，准备图片后插入到占位行位置；
3. **插入图片后删除该行灰色占位文字**，保留下方图题（图X-X）；
4. 图片宽度建议：流程图/用例图 **13~15 cm**，界面截图 **15 cm 或整页宽**，Allure 截图 **15 cm**；
5. 统一使用 PNG 格式，分辨率不低于 150 DPI（截图时浏览器窗口宽度建议 ≥ 1280 px）。

### 图4-12 JWT令牌验证流程

| 项 | 内容 |
|---|---|
| 所在章节 | 4.4.5 用户认证与加密流程设计 → 2) JWT令牌验证流程设计 |
| 图类型 | 时序图（推荐）或流程图 |
| 建议工具 | PlantUML（时序图最省事）、draw.io |

**时序图参与者**：浏览器 → JwtInterceptor → JwtUtils → UserContext

**流程**：

1. 浏览器发起请求，Header 携带 `Authorization: Bearer <token>`
2. 拦截器判断是否为 OPTIONS 预检请求，是则直接放行
3. 取出 token；token 为空 → 返回 **401 未登录**
4. 调用 JwtUtils 校验签名与过期时间
5. 校验失败 → 返回 **401 登录已过期**
6. 校验通过 → 解析 claims（userId / username / role）→ 写入 UserContext（ThreadLocal）
7. 放行请求
8. 请求结束，`afterCompletion` 中清理 ThreadLocal

**说明**：第 5 步「登录已过期」与第 3 步「未登录」是两个不同的 401 分支，建议在图上分别标出。
