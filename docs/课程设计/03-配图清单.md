### 图2.2 用户注册流程图

- 位置：2.2.1
- 节点顺序：
  开始 → 打开注册页 → 填写用户名/密码/邮箱/验证码 → 前端格式校验
  →（不通过）提示错误 → 返回填写
  →（通过）提交注册请求 → 后端校验验证码
  →（无效）提示「验证码错误或已过期」→ 结束
  →（有效）校验用户名是否已存在
  →（已存在）提示「用户名已存在」→ 结束
  →（不存在）BCrypt 加密密码 → 写入用户表 → 提示注册成功 → 结束

### 图2.3 下单与库存扣减流程图

- 位置：2.2.2
- 节点顺序：
  开始 → 勾选购物车商品 → 提交结算 → 校验收货信息
  → 遍历购物车项 → 商品是否存在且上架？
  →（否）抛出异常、事务回滚 → 结束
  →（是）库存是否充足？
  →（否）抛出异常、事务回滚 → 结束
  →（是）累加订单总额 → 写订单主表 → 写订单明细（商品快照）
  → 条件更新扣减库存 → 影响行数是否为 0？
  →（是）抛出异常、事务回滚 → 结束
  →（否）继续下一件（循环）→ 清空已结算购物车项 → 返回订单号 → 结束

### 图2.4 取消订单与库存恢复流程图

- 位置：2.2.3
- 节点顺序：
  开始 → 我的订单 → 选择订单点取消 → 校验订单归属
  →（不属于当前用户）提示无权操作 → 结束
  →（属于）订单状态是否为「待发货」？
  →（否）提示「只能取消待发货订单」→ 结束
  →（是）查询订单明细 → 逐条执行原子更新恢复库存
  → 订单状态置为「已取消」→ 提示取消成功 → 结束

### 图2.5 个性化推荐生成流程图

- 位置：2.2.4
- 节点顺序：
  开始 → 定时任务触发 → 读取用户行为数据 → 按时间衰减聚合
  → 生成用户画像 → 画像是否为空？
  →（是，冷启动）按热度排序 → 生成推荐理由 → 写入推荐结果 → 结束
  →（否）计算内容相似度 → 计算商品热度 → 计算协同过滤得分
  → 按 0.6/0.3/0.1 加权融合 → 排序 → 生成推荐理由 → 写入推荐结果 → 结束

### 图2.6 客服助手问答流程图

- 位置：2.2.5
- 节点顺序：
  开始 → 用户输入问题 → 文本归一化（去标点空格、转小写）
  → 知识库逐条打分（关键词特征度 + 二元组相似度）
  → 最高分是否 ≥ 0.35？
  →（是）返回预置答案 → 结束
  →（否）大模型是否已配置？
  →（否）返回兜底话术 → 记录未命中问题 → 结束
  →（是）今日次数是否用尽？
  →（是）提示次数已用完 → 结束
  →（否）携带最相近条目请求大模型 → 调用是否成功？
  →（否）返回兜底话术 → 记录未命中问题 → 结束
  →（是）返回模型回答 → 记录未命中问题 → 结束
