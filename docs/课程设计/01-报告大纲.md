## 一、模板与论文的差异（决定改写策略）

| 维度 | 论文（毕业设计） | 课设报告（模板） |
|---|---|---|
| 篇幅 | 5 章 + 参考文献，约 3 万字 | 5 章，偏工程实现，图多字少 |
| 重心 | 推荐算法研究与评估 | **系统实现与界面截图** |
| 第1章 | 绪论（背景/现状/研究内容） | 系统描述（设计目的 + **按功能逐个列需求**） |
| 第2章 | 相关技术 + 需求分析 + 总体设计 | 系统设计（模块划分图 + **流程图** + **全部数据表**） |
| 第3章 | 需求分析 | **项目组分工计划**（模板独有） |
| 第4章 | 系统设计 | **系统实现**（逐功能截图 + 说明） |
| 第5章 | 系统实现 | **项目总结**（每人 300 字以上） |
| 特征 | 有算法实验与评估 | 有**附录代码（≤5 页）**、分工表 |

**结论**：论文只覆盖模板的「第1章 1.1 + 第2章 2.1/2.3 + 第4章」；模板的**第3章、第5章、附录、以及 2.2 流程图、4.x 大量界面截图**需要新写或新截。
